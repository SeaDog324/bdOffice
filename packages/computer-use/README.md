# Computer tools

BigDog owns tool definitions, approvals, task identity and effect receipts. An independent helper hosts the Cua SDK for window discovery, observation and input. The existing model connection is reused; the driver does not require Cua Spaces or another model login.

Action delivery and verified completion are separate states. After input, a fresh observation is required. A timeout or helper crash with uncertain delivery requires review before retry. Screenshots are bounded run context and are not restored as usable native window authority.

See [UPSTREAM.md](UPSTREAM.md) and [THIRD_PARTY.md](THIRD_PARTY.md) for versions, licenses and corresponding source. Native SDK/platform package versions must match when building a distribution.
