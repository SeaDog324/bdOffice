# Установка BigDogOffice

Скачайте BigDogOffice со [страницы выпусков](https://github.com/whdite/bdOffice/releases). Доступные платформы, архитектуры и сведения о подписи указаны для каждого выпуска; используйте приложенные к нему файлы.

## Выберите файл для своего компьютера

| Платформа                            | Требования                                            | Файл                          |
| ------------------------------------ | ----------------------------------------------------- | ----------------------------- |
| **macOS** — Apple Silicon            | macOS 11+                                             | `.dmg` (arm64)                |
| **macOS** — Intel                    | macOS 11+                                             | `.dmg` (x64)                  |
| **Windows** — большинство ПК         | Windows 10+, Intel/AMD                                | установщик `-x64-Setup.exe`   |
| **Windows** на Arm                   | Windows 11 на Arm (Snapdragon X и подобные)           | установщик `-arm64-Setup.exe` |
| **Linux** — Debian / Ubuntu          | x86_64, glibc 2.34+ (Ubuntu 22.04 или новее)          | `.deb`                        |
| **Linux** — Fedora / RHEL / openSUSE | x86_64, glibc 2.34+ (Fedora 35+, RHEL 9+, Leap 15.6+) | `.rpm`                        |
| **Linux** — всё остальное            | x86_64, glibc 2.34+, FUSE 2                           | `.AppImage`                   |

Более старые версии остаются на странице релизов.

## В macOS

Откройте `.dmg` и перетащите **BigDogOffice** в «Программы». В сборке для Intel первый запуск попросит подтвердить открытие: щёлкните по приложению в «Программах» правой кнопкой ▸ «Открыть». Это Gatekeeper столкнулся с образом диска, который выглядит неподписанным, а не повреждённая загрузка.

## В Windows

Запустите установщик `.exe`. Он помещает BigDogOffice в меню «Пуск» и регистрирует `.docx`, `.xlsx`, `.pptx`, `.pdf` и подобные форматы как приложения по умолчанию, так что двойной щелчок по файлу открывает его в BigDogOffice.

## В Linux

**Debian / Ubuntu**

```sh
sudo apt install ./BigDogOffice-<version>-amd64.deb
```

**Fedora / RHEL / openSUSE**

```sh
sudo dnf install ./BigDogOffice-<version>-x86_64.rpm     # Fedora / RHEL family
sudo zypper install ./BigDogOffice-<version>-x86_64.rpm  # openSUSE
```

**AppImage** — запускается оттуда, где лежит, без шага установки:

```sh
chmod +x BigDogOffice-<version>-x64.AppImage
./BigDogOffice-<version>-x64.AppImage
```

Ему нужна среда выполнения FUSE 2. Если ставить её не хочется, запустите его с `--appimage-extract-and-run` — и песочница будет работать из распакованного каталога.

## Сборка, которую вы запускаете

**Настройки ▸ О программе** — место, где приложение сообщает, какая у вас сборка, за каким каналом оно следит и где находится проект. Когда на этом канале выходит новая сборка, та же панель предлагает обновление; установка через Flatpak, Nix или Docker этого не делает, потому что её заменяет инструмент, который её туда поставил.

## Командная строка идёт в комплекте

Каждая установка включает команду `bigdogoffice`, которая работает через те же движки, что и окно, поэтому они никогда не расходятся во мнении о файле. В macOS и Windows она лежит внутри пакета приложения; `bigdogoffice install-cli` помещает её в ваш `PATH`. Что она умеет — см. **Командная строка и агенты**.
