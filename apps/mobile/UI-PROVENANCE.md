# Mobile UI attribution

The Android client draws on the navigation and visual conventions of
[dsh-Go](https://github.com/ccch1mneyyy/dsh-Go) at commit
`1c5b220093295f8d069f6bfb06d8b4fc97b9e9c2`. BigDogOffice implements the interface
in uni-app with its own components, icons, branding and interaction code.
