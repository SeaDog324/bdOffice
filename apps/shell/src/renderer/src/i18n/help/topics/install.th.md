# การติดตั้ง BigDogOffice

ดาวน์โหลด BigDogOffice จาก[หน้ารุ่นที่เผยแพร่](https://github.com/whdite/bdOffice/releases) ตรวจสอบแพลตฟอร์ม สถาปัตยกรรม และข้อมูลลายเซ็นของแต่ละรุ่น แล้วใช้ไฟล์ที่แนบมากับรุ่นนั้น

## เลือกไฟล์ให้ตรงกับเครื่องของคุณ

| แพลตฟอร์ม                            | ข้อกำหนด                                              | ไฟล์                          |
| ------------------------------------ | ----------------------------------------------------- | ----------------------------- |
| **macOS** — Apple Silicon            | macOS 11+                                             | `.dmg` (arm64)                |
| **macOS** — Intel                    | macOS 11+                                             | `.dmg` (x64)                  |
| **Windows** — คอมพิวเตอร์ส่วนใหญ่    | Windows 10+, Intel/AMD                                | ตัวติดตั้ง `-x64-Setup.exe`   |
| **Windows** บน Arm                   | Windows 11 บน Arm (Snapdragon X และรุ่นใกล้เคียง)     | ตัวติดตั้ง `-arm64-Setup.exe` |
| **Linux** — Debian / Ubuntu          | x86_64, glibc 2.34+ (Ubuntu 22.04 หรือใหม่กว่า)       | `.deb`                        |
| **Linux** — Fedora / RHEL / openSUSE | x86_64, glibc 2.34+ (Fedora 35+, RHEL 9+, Leap 15.6+) | `.rpm`                        |
| **Linux** — อื่น ๆ                   | x86_64, glibc 2.34+, FUSE 2                           | `.AppImage`                   |

เวอร์ชันเก่ากว่ายังอยู่ในหน้าเผยแพร่

## บน macOS

เปิดไฟล์ `.dmg` แล้วลาก **BigDogOffice** ไปไว้ใน Applications ถ้าเป็นเวอร์ชัน Intel การเปิดครั้งแรกจะถามให้คุณยืนยันการเปิด คลิกขวาที่แอปใน Applications แล้วเลือก เปิด นี่คือ Gatekeeper ที่กำลังเจออิมเมจดิสก์ที่ดูเหมือนไม่ได้ลงลายเซ็น ไม่ใช่ไฟล์ที่ดาวน์โหลดเสีย

## บน Windows

รันตัวติดตั้ง `.exe` ตัวนี้จะวาง BigDogOffice ไว้ในเมนู Start และลงทะเบียน `.docx`, `.xlsx`, `.pptx`, `.pdf` และไฟล์อื่น ๆ ให้เป็นค่าเริ่มต้น ดังนั้นดับเบิลคลิกที่ไฟล์ก็จะเปิดขึ้นมา

## บน Linux

**Debian / Ubuntu**

```sh
sudo apt install ./BigDogOffice-<version>-amd64.deb
```

**Fedora / RHEL / openSUSE**

```sh
sudo dnf install ./BigDogOffice-<version>-x86_64.rpm     # Fedora / RHEL family
sudo zypper install ./BigDogOffice-<version>-x86_64.rpm  # openSUSE
```

**AppImage** — รันจากที่วางไว้ได้เลย ไม่ต้องมีขั้นตอนติดตั้ง

```sh
chmod +x BigDogOffice-<version>-x64.AppImage
./BigDogOffice-<version>-x64.AppImage
```

ตัวนี้ต้องมีรันไทม์ FUSE 2 ถ้าไม่อยากติดตั้ง ให้รันด้วย `--appimage-extract-and-run` แซนด์บ็อกซ์จะทำงานได้จากโฟลเดอร์ที่แตกออกมา

## เวอร์ชันที่คุณกำลังใช้

**การตั้งค่า ▸ เกี่ยวกับ** คือที่ที่แอปรายงานว่าคุณมีเวอร์ชันไหน ติดตามช่องทางอัปเดตไหน และโปรเจกต์นี้อยู่ที่ไหน เมื่อมีเวอร์ชันใหม่กว่าประกาศบนช่องทางนั้น แผงเดียวกันนี้จะเสนอการอัปเดตให้ แต่การติดตั้งแบบ Flatpak, Nix หรือ Docker จะไม่เสนอ เพราะสิ่งเหล่านั้นถูกเครื่องมือที่ติดตั้งมันแทนที่

## บรรทัดคำสั่งมาให้ด้วย

ทุกการติดตั้งมีคำสั่ง `bigdogoffice` ที่คุยกับเอนจินตัวเดียวกับที่หน้าต่างใช้ ทั้งสองฝ่ายจึงไม่มีวันขัดแย้งกันเรื่องไฟล์ บน macOS และ Windows คำสั่งนี้อยู่ในแพ็กเกจของแอป ถ้าต้องการเรียกด้วยชื่อ ให้รัน `bigdogoffice install-cli` ครั้งเดียว คำสั่งจะไปอยู่ใน `PATH` ของคุณ ดู **บรรทัดคำสั่งและเอเจนต์** ว่ามันทำอะไรได้บ้าง
